# Student Burnout Prediction Using Machine Learning and RWR

## Project Overview

This project focuses on analyzing and predicting student burnout levels using Machine Learning techniques.

The dataset contains 150,000 student records with 19 features related to academic performance, lifestyle, stress, and other factors.

## Objective

- Analyze factors related to student burnout
- Perform Exploratory Data Analysis (EDA)
- Create a Rest-to-Work Ratio (RWR) feature
- Compare multiple Machine Learning models
- Evaluate model performance
- Identify important features and generate insights

## Dataset

- Source: Kaggle
- Records: 150,000
- Features: 19
- Target: Burnout Level
- Classes: High, Medium, Low

## Machine Learning Models

1. Decision Tree
2. Random Forest
3. Logistic Regression
4. K-Nearest Neighbors (KNN)
5. Support Vector Machine (SVM)
6. XGBoost

## Best Model

KNN achieved the highest accuracy among the evaluated models with **33.76% accuracy**.

## Important Features

- CGPA
- Attendance Percentage
- Rest-to-Work Ratio (RWR)
- Daily Study Hours
- Screen Time Hours
- Daily Sleep Hours
